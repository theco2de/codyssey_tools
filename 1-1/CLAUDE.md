# 코디세이 과제: AI Agent에게 일 제대로 시키는 법

- 과업: 수강생 Spring 기술 질문 답변 초안 (페르소나 "스프링 조교". 실행한 프롬프트 본문에는 당시 이름 "봄 조교"가 그대로 남아 있음)
- 산출물: docs/model-comparison.md, system-design.md, run-log.md, unresolved.md → GitHub 제출
- 진행 상황(2026-11-24): 모델 비교·선정(Claude Sonnet 5.5), Zero/Few-shot 비교, v1 24턴 실행과 H1~H7 판정, v2 작성과 재실행, unresolved 2건 초안까지 완료. 남은 것 = 사용자 검토(H5·H7 판정, ⚠️ 등급, unresolved 막힌 이유), (선택) 보너스 과제. GitHub 업로드는 완료(private 저장소 theco2de/codyssey_tools의 1-1 폴더), 이후 수정분은 커밋과 push 필요

## 사용자
- 부트캠프 강사(Java/Spring 백엔드 교안 작성). 현업 과업 정의가 없어서 강사 업무에서 과업을 골랐다.
- 후보 비교: A 질문 답변 초안(선택) / B 복습 퀴즈 생성 / C 수업 공지문. A를 고른 이유는 반복이 잦고, 사실 검증이 쉽고, 되묻기 예시를 만들기 쉽기 때문이다.

## 설계 핵심 (자세한 내용은 docs/system-design.md)
- 수강생 기본 설정: Windows, IntelliJ, Spring Boot 3.x, Java 17. JPA와 Security는 아직 안 배움. curl 대신 브라우저와 Postman을 쓴다.
- 출력 형식은 4단이다: 원인 추정 → 확인 방법(최대 3단계) → 해결 힌트(코드 3줄 이하) → 함께 볼 개념. 불확실한 내용은 "확인 필요"로 붙이고, 정보가 부족하면 되묻기 질문만 최대 3개 쓴다.
- 비교용 질문(model-comparison.md): Q1 포트 8080 충돌, Q2 javax→jakarta, Q3 NoUniqueBean. 채점 기준은 5개이고 정답표는 §5에 있다.
- Few-shot 예시 4건: 404 경로 오타, 415 Content-Type, 모호한 입력 되묻기, JPA 범위 밖 질문. 비교용 질문과 겹치지 않게 만들었다.
- 검증 질문 H1~H7은 run-log의 홀수 턴 7~19번에 들어 있다.
  - H3: 일부러 틀린 전제("기본 포트가 8000으로 바뀌었다")
  - H4: 스프링에 없는 애노테이션 `@AutoInject`
- 24턴 시나리오
  - 3번째 턴: 1번째 턴과 같은 입력 반복
  - 5번째 턴: 조건 변경("@Qualifier 금지")
  - 21번째 턴: 공지 3문장 요청. 카테고리를 표시한 프롬프트 3번이다.
  - 23번째 턴: javax 질문과 함께 터미널 확인 방법을 묻는다. curl과 Windows 조건이 지켜지는지 확인한다.

## 남은 단계
1. 사용자가 초안을 검토하고 run-log 작업 기록에 적는다.
2. 모델 3종에 Q1~Q3를 실행한다. 모델명, 버전, 실행 시각, 스크린샷(docs/img/)과 원문을 붙인다.
3. 사용자가 채점하고 모델을 고른다. 선정 근거는 사용자가 직접 쓴다.
4. Zero-shot과 Few-shot을 비교하고(system-design §6), 단계적 추론 유도를 넣을지 정한다.
5. 선정한 모델에 v1을 적용해 24턴을 진행하고 원문을 붙인다.
6. Pass/Fail을 판정하고(사용자 몫) ⚠️ 지점을 표시한다.
7. v2를 작성하고 다시 실행한다(§9).
8. unresolved에 2건 이상 쓴다.
9. git init을 하고 GitHub에 올린다.
10. (선택) 보너스 과제: 커스텀 인스트럭션 배포, 이미지 생성, Apps Script 호출.

Claude가 도울 수 있는 일: 원문을 붙인 뒤 점수표 정리, 의심 지점 짚기(판정은 사용자가 함), v2 다듬기, git 작업.

## 규칙
- 한국어 해요체로 답한다.
- ✍️ 칸(모델 선정 이유, 프롬프트 수정 이유, 막힌 이유, Pass/Fail 판정)은 사용자가 작성을 요청할 때만 쓴다. 요청이 없으면 비워 두고, 판단 재료만 제시한다. (2026-11-24 사용자가 규칙 완화)
- 대화 로그는 실제 모델 응답 원문 그대로 둔다. 편집하지 않는다.
- API 키, 비밀번호, 계정 이메일은 문서에 넣지 않는다.
- 커밋에 Claude 공동 작성자 줄이나 "Generated with" 줄을 넣지 않는다.
