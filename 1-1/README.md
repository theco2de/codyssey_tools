# AI Agent에게 일 제대로 시키는 법 — 수강생 기술 질문 답변 초안

Spring 입문 부트캠프 수강생이 올리는 기술 질문(에러 로그, 개념 질문)에 대해
조교 답변 초안을 LLM으로 만드는 과업을 대상으로, 모델 비교 → 페르소나·프롬프트 설계 → 실제 대화 → 검증·개선 → 미해결 기록까지 남긴 저장소예요.

## 읽는 순서

| 순서 | 문서 | 한 줄 소개 |
|---|---|---|
| 1 | [docs/model-comparison.md](docs/model-comparison.md) | 같은 과업 프롬프트를 모델 3종에 넣고 기준 5개로 비교한 뒤 선정한 보고서 |
| 2 | [docs/system-design.md](docs/system-design.md) | 과업 정의, 페르소나, 시스템 프롬프트, Few-shot, 입력 템플릿, 검증 전략, v1→v2 개선 이력 |
| 3 | [docs/run-log.md](docs/run-log.md) | 선정 모델과 나눈 10턴 이상 대화 원문(편집 없음), 환각·문맥 끊김 표시, 작업 기록 |
| 4 | [docs/unresolved.md](docs/unresolved.md) | 프롬프트를 고쳐도 원하는 결과를 얻지 못한 과업과 막힌 이유 |

보조 자료: `docs/raw/`(모델 실행 키트), `docs/img/`(실행 화면 스크린샷)
